このポリシーについて

このポリシーは YaoPilot iPhone アプリ（簡体字中国語名：遥点）と本サイトに適用されます。alpha2z は個人開発者が使用する公開名です。アプリにはアカウント登録、広告、分析 SDK、開発者が運営するクラウド機能はありません。

アプリで扱う情報

アプリはテレビのブランド、ローカル IP アドレス、事前共有キー、操作指令を使用し、状態、キーの対応状況、入力名、アプリの起動項目を読み取ります。これらを開発者に送信しません。テレビ情報とアプリ一覧はメモリ内で使用し、保存する接続情報は端末のキーチェーンに保管します。言語と振動の設定は端末内に保存します。

ローカル通信と安全性

対応テレビのインターフェースは HTTP を使用するため、キーはローカルネットワーク上で指令とともに送信され、通信経路は暗号化されません。信頼できるホームネットワークを使用し、制御ポートをインターネットに公開しないでください。テレビとの通信にローカルネットワーク権限を使用し、iPhone の設定から変更できます。

保存と削除

接続設定で保存したテレビを削除すると、対応するキーチェーン項目とアプリ内の接続情報を削除します。アンインストール後もキーチェーン情報が残る場合があるため、先に接続情報を削除してください。キーはこの端末のみで、ロック解除後にアクセスできる設定で保存し、iCloud 同期を有効にしていません。環境設定は変更またはアプリデータの削除まで端末内に残り、システムのバックアップは iOS が管理します。テレビ側の設定やアカウントは削除しません。

サイトのホスティング

GitHub Pages で公開された場合、GitHub はサイトへのリクエストを処理し、ログインの有無にかかわらず安全性のために訪問者の IP アドレスを記録します。これはアプリのローカル操作とは別の処理です。本ページには追加の分析、広告、フォーム、外部フォント、追跡スクリプトはありません。GitHub の取り扱いは同社のプライバシー声明をご確認ください。

サポートメール

otsgame@yahoo.com にメールを送ると、開発者は送信者のアドレス、本文、添付資料を受け取ります。メール事業者も配信を処理します。必要な情報のみを送り、テレビのキー、パスワード、自宅の IP アドレス、端末のシリアル番号は送らないでください。お問い合わせへの対応や適用される義務に必要な期間のみ通信を保持します。同じアドレスで照会や削除の依頼を受け付けます。

変更とお問い合わせ

アプリやホスティングの取り扱いが変わる場合、本ポリシーと施行日を更新します。プライバシーに関するお問い合わせは otsgame@yahoo.com までお願いします。アプリは広告目的のデータ収集やユーザーデータの販売を行いません。
